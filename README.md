## Skill

`skills/wp-navigation-overlay/` is a portable SKILL.md agent skill that works with Claude Code, Copilot CLI, Gemini CLI, and other compatible assistants. Copy the folder into your assistant's skills directory, then describe what you want, e.g. "make me a minimal navigation overlay for a typographer's portfolio", and you'll get back ready-to-paste block markup.
